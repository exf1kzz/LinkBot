# LinkBot

Telegram-бот для сохранения ссылок и получения их обратно в дальнейшем.

## Возможности

- Сохранение любых URL-ссылок, отправленных боту.
- `/rnd` — отправляет случайную сохранённую ссылку и удаляет её из хранилища.
- `/all` или `/list` — отправляет все сохранённые ссылки без удаления.
- Поддержка двух типов хранилищ:
  - **SQLite** — для постоянного хранения в реляционной базе данных. (Рекомендуемое)
  - **Файловое хранилище** — для хранения ссылок в файловой системе (бинарный формат gob).
- Docker и Docker Compose для запуска проекта.

## Настройка

Создайте локальный файл `.env`:

```env
TG_BOT_TOKEN=123456789:replace-me
STORAGE_PATH=data/sqlite/storage.db
```

`TG_BOT_TOKEN` — токен Telegram-бота, обязательный параметр.

`STORAGE_PATH` — путь к SQLite-базе данных. Параметр необязательный, по умолчанию используется `data/sqlite/storage.db`.

Также параметры можно передать через CLI-флаги:

```bash
go run . -token "123456789:replace-me" -storage-path "data/sqlite/storage.db"
```

Флаг `-token-bot` также поддерживается для обратной совместимости, но рекомендуется использовать `-token` или переменную окружения `TG_BOT_TOKEN`.

## Локальный запуск

Установите зависимости:

```bash
go mod download
```

Запустите бота:

```bash
go run . -token "$TG_BOT_TOKEN"
```

## Запуск с Docker

Создайте `.env` на основе примера:

```bash
cp .env.example .env
```

Запустите контейнер:

```bash
docker compose up --build -d
```

## Команды

| Команда | Описание |
|---|---|
| `/start` | Показать приветственное сообщение |
| `/help` | Показать список доступных команд |
| `/rnd` | Получить случайную сохранённую ссылку и удалить её из хранилища |
| `/all` | Получить все сохранённые ссылки |
| `/list` | Алиас для `/all` |

## Хранение данных

Сохранённые ссылки хранятся в SQLite-базе данных.

По умолчанию используется:

```text
data/sqlite/storage.db
```

## Конфиденциальность

Не добавляйте в Git:

- `.env` с токеном бота;
- директорию `data/`;
- локальные базы данных;
- собранные бинарные файлы;
- файлы и директории IDE.

Эти файлы добавлены в `.gitignore`.
